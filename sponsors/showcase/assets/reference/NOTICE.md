# Original Look animation assets

Retrieved from the project owner's public Look deployment:
https://look-website-kappa.vercel.app/ (2026-10-18).
These are the same compiled tabletop RobotScene component and dependencies, reused
at the user's request to preserve the original Medicine/Mug/Water/Phone animations.
See provenance.json for source hashes and the renderer adaptation. The full upstream
site is not mounted. No sponsor actions are implemented in these vendor modules.
Bundled dependencies include React/React DOM (Meta, MIT) and Three.js (Three.js
authors, MIT); existing bundled license comments are preserved. Do not assume this
notice grants rights to unrelated third-party website assets.
